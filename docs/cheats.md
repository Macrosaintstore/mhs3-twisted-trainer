# Cheats

- **infinite_health** — pins rider HP. Disable before cutscenes to avoid scripted damage skipping.
- **infinite_stamina** — stamina stays at max during traversal.
- **max_monstie_bond** — fills the kinship gauge; the game will reset it on combat start.
- **free_item_craft** — bypasses the material check in the crafting menu.
- **instant_kinship_skill** — allows the kinship skill without the gauge.
- **gene_editor** — unlocks all gene slots on the selected monstie. Back up your save first.
- **no_egg_cooldown** — removes the egg-hatching cooldown timer.
