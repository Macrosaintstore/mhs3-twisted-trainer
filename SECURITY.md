# Security Policy

This project is a hobbyist memory-editing trainer for Monster Hunter Stories 3: Twisted Reflection.
It attaches to the game process via `pymem` and writes to known offsets.

## Supported versions
Only the latest Steam build is supported. Report offset breakage via Issues.

## Reporting a vulnerability
If you find a memory-corruption bug in the trainer itself (not in the game), email the maintainer listed in the repo profile. Do not publish a PoC that crashes the game for other users.

## Out of scope
- Anti-cheat bypasses for multiplayer modes (MHS3 has none; the trainer targets single-player only).
- Requests to add online play modifications.

## Disclaimer
Use at your own risk. Back up your save files before enabling any cheat that touches save state.
